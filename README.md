## 🚀 طرق تشغيل المعرض محلياً (Local Preview)

يمكنك استعراض الموقع فورياً بأي من الطرق التالية:
1. **النقر المزدوج** مباشرة على ملف `index.html` ليفتح في أي متصفح (Chrome, Edge, Firefox).
2. **عبر خادم محلي خفيف (Live Server)**:
   إذا كنت تستخدم VS Code: انقر بالزر الأيمن على `index.html` واختر `Open with Live Server`.
   أو باستخدام بايثون من سطر الأوامر:
   ```bash
   python -m http.server 8000
   ```
   ثم افتح: `http://localhost:8000`

## 🌐 طرق النشر المجاني الفوري على الإنترنت (Free Hosting)

الموقع مبني بـ HTML/CSS/JavaScript نقية وجاهزة للنشر المباشر على جميع المنصات السحابية المجانية:

### 1. النشر عبر Netlify (الأسهل في 10 ثوانٍ):
1. افتح موقع **[Netlify Drop](https://app.netlify.com/drop)**.
2. اسحب مجلد المشروع `islam-fajam-portfolio` بالكامل وأفلته في الصفحة.
3. ستحصل على رابط حي دائم مجاني (مثل: `https://islam-fajam-portfolio.netlify.app`) مع شهادة SSL مجانية.

### 2. النشر عبر GitHub Pages:
1. أنشئ مستودعاً جديداً على GitHub باسم `portfolio` أو `islam-fajam-portfolio`.
2. ارفع الملفات (`index.html`, `style.css`, `script.js`).
3. توجّه إلى إعدادات المستودع (Settings) -> ثم قسم **Pages**.
4. اختر الفرع `main` والمجلد `/ (root)` واضغط **Save**.
5. سيصبح المعرض متاحاً على: `https://YOUR_GITHUB_USERNAME.github.io/portfolio/`

### 3. النشر عبر Vercel أو Render:
- استورد المستودع من GitHub واختر Static Site، وسيتم النشر في أقل من دقيقة.
